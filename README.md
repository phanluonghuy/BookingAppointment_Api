# BookingAppointmentApi

This repository contains the backend API for the Doctor Pill booking appointment system.

## Installation

To get started with the API, follow these steps:

1. Clone the repository:
    ```sh
    git clone https://github.com/phanluonghuy/BookingAppointment_Api.git
    ```
2. Navigate to the project directory:
    ```sh
    cd BookingAppointment_Api

3. Run the application:
    ```sh
    docker-compose up
    ```
